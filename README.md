# 👤 My Personal Profile Website

## 📌 About the Project
My Personal Profile is a simple personal website created using HTML. It introduces me, shares my hobbies, and highlights my skills. The website uses a clean structure with navigation links to help visitors explore different sections.

## ✨ Features
- 🏠 **Home:** Displays the profile heading and a welcome tagline.
- 👋 **About:** Introduces me and provides a short description.
- ⚽ **Hobbies:** Showcases football, gaming, and traveling.
- 💡 **Skills:** Displays my skills, including football, CSS, creativity, and problem-solving.
- 🧭 **Navigation Bar:** Allows visitors to jump between sections.
- 📄 **Footer:** Displays the creator's name and copyright information.

## 🛠️ Technologies Used
- HTML5
- Basic web development concepts

## 📁 Project Structure
```text
My-Personal-Profile/

├── profile.jpg

├── hobby2.jpg

```

## 🚀 How to Run the Project
1. Download or clone this project.
2. Keep the image files in the same folder as `index.html`.
3. Open `index.html` in any modern web browser.
4. Explore the different sections using the navigation bar.

## 🎯 Learning Objectives
- Understand the basic structure of an HTML document.
- Learn how to use headings, paragraphs, images, and links.
- Create sections using `<section>` and `<div>` elements.
- Use IDs and anchor links for page navigation.
- Organize content using semantic HTML elements.
